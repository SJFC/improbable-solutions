# The Ministry of Improbable Solutions to Small Problems

First-draft working prototype of the Ministry website. Plain HTML, CSS and JavaScript.

This is a very early draft, with placeholder text, as part of an initial MDes hand-in before the site is further developed.
It is frozen, as an example of work in progress. A sister repo has been developed where work is ongoing.

## Files

- `index.html` — the consultation (home) page
- `broadside.html` — one report (No. 40) with the registers beneath it
- `styles.css` — all styling for both pages
- `script.js` — dealing the creature and form; the objection and amendment flow
- `images/theatre.jpg` — the paper-theatre collage
